# MailCairn interface research — 2026-11-09

All links below were reviewed on 2026-11-09. This supplements `design-research.md`; it does not establish user demand or claim that a particular appearance proves AI authorship. The immediate evidence is the owner's feedback about small text, repetitive copy, rigid buttons, generic focus boxes and disconnected decorative effects. Recommendations below are design judgments to verify in the running product.

## Focused implementation direction

1. **Make the archive readable first.** Start from approximately 16px everyday UI text, 16–18px message text and 14px genuinely secondary metadata. These numbers are a proposal, not a WCAG requirement. Use a small role-based scale; check the result at narrow widths, zoom and with long subjects. Keep useful labels visible instead of relying entirely on placeholders.
2. **Cut copy by function.** Preserve format restrictions, import failures, duplicate accounting, recovery actions and backup instructions where they affect decisions. Remove repeated branding, catalogue captions and sentences that merely describe what the visible control already does. Empty state: a short heading, one useful sentence and one import action.
3. **Soften controls without losing hierarchy.** Give primary actions rounded geometry, comfortable padding and a restrained tonal surface. Secondary actions can be quieter text or low-emphasis surfaces. Keep hit areas usable even if the visible decoration is small. Selection and focus must remain distinguishable.
4. **Put the memorable interaction inside the task.** Treat a message as a sheet moving from the result list into a stable reading surface, or let the import target resolve into the newly populated archive. Use one coherent spatial relationship and bounded light/edge feedback. This is an original proposed interaction, not copied from a source example.
5. **Let frequent work stay immediate.** Use short feedback for hover, press and filter changes; reserve a longer reveal for opening or import completion. Respect reduced motion, cancel obsolete animations, stop effects on hidden surfaces, and maintain reliable focus restoration. Do not claim performance from the chosen CSS properties alone.
