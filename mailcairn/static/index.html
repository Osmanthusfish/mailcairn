Connect a mailbox

Choose your email provider below for step-by-step instructions.

Gmail
  1. In your Google Account, turn on 2-Step Verification.
  2. Create a Google app password for MailCairn. This is a separate password for this app, not your usual Google password.
  3. Choose Gmail in MailCairn, enter your full Gmail address and the app password, then choose Start syncing.

App passwords may be unavailable for work or school accounts, Advanced Protection, or some security-key-only setups. If Google does not offer one, import a Google Takeout export instead.

Proton Mail
  1. Automatic sync requires a paid Proton Mail plan and Proton Mail Bridge installed on this computer. Proton Free does not support this connection.
  2. Open Bridge and sign in to Proton there. Keep Bridge running while MailCairn syncs.
  3. Copy the username and password shown in Bridge's mailbox settings into MailCairn. Your usual Proton account password will not work here.

The default Bridge port is 1143. If Bridge shows a different IMAP port, open Advanced settings in MailCairn and enter that number. The local Bridge connection uses STARTTLS; MailCairn remembers its certificate and stops if it changes.

Without a paid plan, use Proton Mail Export Tool to export EML files, then import the folder into MailCairn. File import does not require Bridge.

Other email providers

Find your provider's incoming-mail settings for IMAP. You need the incoming server address, your username (often your full email address), and a password. Some providers require a separate app password or enabling IMAP first.

Enter those details under Other email. The default port is 993, using an encrypted SSL/TLS connection. Only change the port in Advanced settings if your provider specifies another SSL/TLS port. Unencrypted connections and remote STARTTLS-only servers are not supported.

MailCairn cannot connect to a provider that requires OAuth sign-in only. You can still import its exported mail files.

What happens after connecting

The first sync saves existing mail from your inbox (INBOX). MailCairn then checks for new mail every 5 minutes while it is running. Other folders and Sent are not included.

After a connection error, automatic retries continue while MailCairn is running, the mailbox is not paused, and its password is available. A retry may still fail until the connection is available again.

If Gmail opens in your browser but syncing fails, your network may allow the website but block mail connections. A connection error alone does not mean the app password is wrong. You can leave other apps running and import a Google Takeout export instead.

Closing the browser tab does not stop sync; quitting MailCairn does. Mail moved out of the inbox or deleted before the next check can be missed.

Adding a mailbox saves its settings; it does not confirm that sign-in worked. Open Mailboxes to check the status, last successful sync time and saved count. Choose View mail to read the archive. Sync now checks immediately; Pause stops future checks. Disconnect removes the connection but keeps archived mail.

MailCairn only reads and copies mail. It does not send mail, mark it as read, or delete it from your provider.

On Windows, when Remember on this computer is available, it protects the password with your Windows account using DPAPI. Otherwise, or when you turn this option off, the password stays only in memory. You must reconnect with your password after restarting MailCairn.

Mailbox settings and passwords are stored separately from the mail database and are not included in Back up archive. The mail archive itself is not encrypted; protect the computer and your backup copies.

01

Export from your mail app

For Gmail, use Google Takeout, select Mail, download the export, and unzip it. Locate the .mbox file. Thunderbird can also export MBOX using ImportExportTools NG.

Proton Mail: use the Proton Mail Export Tool to export EML files, then choose the exported folder here. JSON sidecar files are skipped. A paid Bridge subscription is not required for this workflow.

Individual messages saved as .eml work too. ZIP, PST, OST, and mboxcl are not supported.

02

Import and review the receipt

Select one or more files. MailCairn preserves message bytes and builds a search index. Import the same file again safely: byte-identical messages are stored once.

The default limits are 20 GiB per file and 32 MiB per message. Oversized or unreadable records appear in the receipt, rather than disappearing silently.

03

Find what you need

Search subject lines, senders, recipients, body text, and attachment names. Use dates or “Has attachments” to narrow the results. Words are matched together; CJK text uses substring search.

Emails are displayed as plain text. Remote images, tracking pixels, scripts, and HTML layouts are not loaded. Download the original EML when you need it.

04

Make a separate backup

Use Back up archive to save a consistent SQLite copy containing your mail, attachments, index, and import receipts. Keep a copy on another drive.

In the desktop window, choose “Restore backup…” to verify and open a copy in a new folder. From source, run:python app.py --data-dir restored --restore-backup archive.sqlite3See the included README for details.

Local, with clear limits

The archive is not encrypted. Anyone who can access your files may read it. Use your operating system’s disk encryption and protect your backups. “Check archive integrity” checks stored bytes and the search index; it does not certify a complete provider export.
